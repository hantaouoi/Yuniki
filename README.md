# 📑 Шпаргалка по Git и Linux 

## 🧭 1. Навигация в терминале Linux
* `cd ~/Yuniki` — зайти в папку вашего проекта.
* `cd ~` — вернуться в главную (домашнюю) директорию.
* `cd ..` — сделать один шаг назад (вверх на одну папку).
* `pwd` — показать полный путь к папке, где вы сейчас находитесь.
* `ls` — показать список файлов в текущей папке.
* `cat test.py` — вывести содержимое файла на экран без открытия.

## 📝 2. Работа с текстовым редактором NANO
* `nano task2.py` — открыть или создать файл в терминале.
* `Ctrl + O` -> затем `Enter` — сохранить (записать) файл на диск.
* `Ctrl + X` — выйти из редактора обратно в терминал.

## 🔄 3. Навигация по веткам в Git
* `git branch` — показать список локальных веток.
* `git branch -a` — показать вообще все ветки (включая те, что в облаке GitHub).
* `git switch feat/change-found` — переключиться на вашу второстепенную ветку.
* `git switch main` — вернуться на главную ветку.

## 📦 4. Ежедневный рабочий цикл Git (Сохранение кода)
1. `git status` — проверить, какие файлы изменились (красные/зеленые).
2. `git add task1.py` (или `git add .`) — упаковать изменения в коробку перед сохранением.
3. `git commit -m "сообщение"` — сделать снимок истории (сохранить на ПК).
4. `git push origin feat/change-found` — отправить сохраненный код (или восстановить удаленную ветку) в облако GitHub.

## 🚨 5. Спасательные команды Git
* `git log --oneline` — посмотреть историю прошлых коммитов в одну строчку (выход из режима на клавишу `q`).
* `git reflog` — журнал всех перемещений (нужен для поиска хэш-кода удаленной ветки).
* `git rm test.py` — правильно удалить файл из проекта и из Git.

# 📦 Инструкция: Настройка и работа с Git на Windows

## 🟩 Шаг 1. Скачивание и установка
1. Перейдите на официальный сайт: https://git-scm.com
2. Скачайте версию **64-bit Git for Windows Setup**.
3. Установите программу, оставляя все галочки по умолчанию (просто нажимайте **Next**).

## 🚀 Шаг 2. Запуск терминала
* Перейдите в любую папку на компьютере (например, на Рабочий стол).
* Нажмите **правой кнопкой мыши** на пустом месте.
* Выберите пункт меню: **`Git Bash Here`**.
* Перед вами откроется привычная Linux-консоль.

## 🟨 Шаг 3. Первичная настройка (Выполняется 1 раз)
Представьтесь Git, чтобы он разрешил вам делать коммиты:
```bash
git config --global user.name "azanmakai"
git config --global user.email "ваша_почта@example.com"
```

## 🟦 Шаг 4. Клонирование вашего проекта Yuniki
Скачайте проект из облака на ваш локальный Windows-ПК:
```bash
# 1. Скачиваем репозиторий
git clone https://github.com

# 2. Заходим в созданную папку проекта
cd Yuniki

# 3. Переключаемся на вашу рабочую ветку
git switch feat/change-found
```

## 🟧 Шаг 5. Ежедневный рабочий цикл (Сохранение кода)
Когда вы изменили или создали новые файлы в папке проекта, выполните цепочку:
```bash
1. Проверяем, что изменилось (файлы горят красным)
git status

2. Добавляем все изменения в индекс (файлы станут зелеными)
git add .

3. Создаем снимок истории (Коммит)
git commit -m "напишите что вы сделали"

# 4. Отправляем изменения обратно в облако GitHub
git push origin feat/change-found
